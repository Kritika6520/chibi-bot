# chibi-bot

Chibi-Bot is an expressive, voice-activated 2D virtual pet. I built this mostly as a timepass project for fun, but it ended up featuring a pretty cool "Hybrid Brain" architecture that switches between lightning-fast offline rules and Google Gemini AI.

## Features
* **Hybrid Brain:** Toggle seamlessly between an offline knowledge base and the Google Gemini API.
* **Native Voice:** Browser-based speech recognition (listening) and synthesis (talking).
* **Organic SVGs:** Dynamic inline SVG paths for genuine, shape-shifting facial expressions.
* **Custom CSS Physics:** CSS keyframes for breathing, walking illusions, and interactive petting.
* **Cyberpunk UI:** Dark-mode dashboard with live health/love meters and quick-action triggers.

## Tech Stack
* HTML5 & Inline SVG
* Tailwind CSS
* Vanilla JS 
* Google Gemini REST API & Web Speech API
